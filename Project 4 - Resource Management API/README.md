# 📚 Resource Management API Testing using Postman

## 📌 Project Overview

This project demonstrates end-to-end API testing of a **Resource Management System** using **Postman**. It covers complete CRUD operations along with negative testing to validate API behavior under different business scenarios.

The project emphasizes structured API validation using JavaScript-based Postman test scripts and reusable environment variables.

---

## 🚀 APIs Covered

### 📖 Resource Operations

- Get All Resources
- Get Single Resource
- Create New Resource
- Update Existing Resource
- Delete Resource
- Negative Validation – Resource Does Not Exist
