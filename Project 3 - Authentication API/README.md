# 🔐 Authentication API Testing using Postman

## 📌 Project Overview

This project demonstrates comprehensive API testing of an **Authentication System** using **Postman**. It validates user authentication, registration workflows, negative login scenarios, and response time behavior through reusable JavaScript test scripts.

The project focuses on functional validation, business rule verification, and negative testing to ensure the reliability of authentication APIs.

---

## 🚀 APIs Covered

### 🔑 Authentication

- Login – Generate Authentication Token
- Negative Login – Missing Password
- Negative Login – Missing Email

### 👤 User Registration

- Successful Registration
- Failed Registration

### ⏱ Performance

- Delayed Response Validation
