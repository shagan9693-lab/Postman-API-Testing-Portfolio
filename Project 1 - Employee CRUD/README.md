# Project 1 – Employee CRUD API Testing

## Project Overview
This project demonstrates API testing using Postman by validating CRUD operations on the Employee API.

## APIs Covered

- GET All Employees
- GET Single Employee
- POST Create Employee
- PUT Update Employee
- DELETE Employee

## Validations Performed

- Status Code Validation
- Response Time Validation
- Structure Validation
- Data Type Validation
- Business Validation

## Postman Concepts Used

- Collection Variables
- Tests Tab
- JavaScript Assertions
- JSON Parsing
- Chai Assertions

## Note

The demo Employee API occasionally returns inconsistent data types for
`employee_salary` and `employee_age` (string/number) and sometimes returns HTTP 429 (Too Many Requests). These are API-side inconsistencies rather than issues with the test scripts.
